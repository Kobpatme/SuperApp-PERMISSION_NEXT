# อาคารและค่าใช้จ่าย
[[00 - SuperApp Home|หน้าเริ่มต้น]] · [[30-Planning/แผนงานและรายการตรวจสอบ|แผนงาน]]

## แนวคิดเดิม
[[20-Modules/Originals/โมดูล รายละเอียดค่าใช้จ่ายของอาคาร|โน้ตทดลองต้นฉบับ]]: เก็บข้อมูลอาคาร ค่าใช้จ่าย สถานะ และค่าใช้จ่ายเพิ่มเติม

## ขอบเขตตามเอกสารเดิม
- แผนที่ รายการ ค้นหา/กรอง และรายละเอียดอาคาร
- Create/Edit, duplicate detection และการจัดการแทน hard delete
- เงื่อนไข, BOQ, ค่าธรรมเนียม และ revenue share
- ใบเสนอราคา: คำนวณ, version, approval, export และ history
- เอกสาร: ค้นหา, preview, download/upload ตามสิทธิ์
- ความสัมพันธ์กับงานและเงินประกัน ผ่าน Building identity กลาง

## สิ่งที่ต้องตรวจใหม่
Audit เดิมระบุว่ามี read/map experience แต่ operational flow บางส่วนยังไม่ครบ ข้อนี้เป็นสถานะใน baseline เก่า ไม่ใช่ข้อสรุปปัจจุบัน

- [ ] ตรวจ CRUD และ duplicate resolution ในโค้ดปัจจุบัน
- [ ] ตรวจ quotation workflow และ calculation tests
- [ ] ตรวจ file access, upload limits และ no-overwrite
- [ ] ตรวจ search/pagination/map query และ Building 360
- [ ] ตรวจสิทธิ์และ audit ของ mutation
