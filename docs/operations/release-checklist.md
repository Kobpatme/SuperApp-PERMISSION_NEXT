# Production release checklist

- [ ] Production schema and data profile approved
- [ ] Live migration dry run and reconciliation approved
- [ ] Live authorization/RLS negative-path tests pass
- [ ] Threat model and privacy/retention review approved
- [ ] Backup created and restore drill evidence current
- [ ] Load/accessibility/browser tests meet targets
- [ ] Secrets, domains, storage provider and Microsoft 365 settings verified
- [ ] Monitoring alerts and on-call/incident ownership assigned
- [ ] Deployment and module rollback rehearsed
- [ ] Domain owners approve KPI, guarantee and pricing rules

Repository gates alone do not satisfy this checklist.
