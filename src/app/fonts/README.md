# Bundled fonts

Unmodified Fontsource Variable 5.3.0 WOFF2 subsets: Manrope Latin (24,836 bytes), Nunito Latin (39,128), Noto Sans Thai Thai (26,924), Source Code Pro Latin (22,044). Each corresponding `*-OFL.txt` contains its upstream SIL Open Font License and copyright notices.

Downloaded at development time from the respective `@fontsource-variable/*` npm packages. No runtime font provider or network access is needed. `next/font/local` applies swap and local fallback metrics; Latin and Thai variables form the UI/heading stacks. Mono is not preloaded. Measured login download evidence is in `docs/quality/ux-login-evidence/font-budget.json`.
